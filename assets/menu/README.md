# Launch artwork

`singapore-old-new-torn.png` is the active title background: a generated photographic-style blend of old Boat Quay and contemporary Singapore, joined with an irregular paper edge. It is conceptual artwork, not a historical photograph or exact viewpoint. The un-torn source is retained as `singapore-old-new.png` for future art revisions.

Both images were made with the built-in ImageGen tool. The complete original and editing prompts are in `BACKGROUND_PROMPT.md`.

`sparky-plush.png` is a separate generated plush portrait, made with the built-in ImageGen tool using the existing Sparky wave render as a character reference. The original alpha is preserved. A small local shader motion animates his raised paw while leaving his face and body still; it pauses while the chapter browser is open. The generation prompt is in `SPARKY_PROMPT.md`.
