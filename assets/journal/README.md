# Journal illustrations

Original SVG UI drawings for Sparky Discovery, using the game's paper, teal, gold and brick palette. These are decorative story illustrations, not historical photographs or documentary evidence.

Uncle Tan's portrait follows the fictional character's dark hair and brick shirt. The antenna and television recall the chapter's props. Homes, jobs and future illustrate optional historical topics; the calendar marks timeline dates.

Each illustration is paired with a readable text label. SVGs use a 120 × 120 viewBox so they stay sharp when resized in Godot.
